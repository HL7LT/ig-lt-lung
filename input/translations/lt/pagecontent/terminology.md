### Terminologija

Šiame puslapyje aprašomos Lietuvos plaučių vėžio diegimo vadove apibrėžtos CodeSystem ir ValueSet kolekcijos.

#### Kodų sistemos (CodeSystem)

| Kodų sistema | Aprašymas |
|---|---|
| [LungRadsCategory](CodeSystem-lung-rads-category.html) | LUNG-RADS vertinimo kategorijos (0, 1, 2, 3, 4A, 4B, 4X), paremtos ACR LUNG-RADS v2022. |
| [LungRadsModifier](CodeSystem-lung-rads-modifier.html) | LUNG-RADS modifikatorių kodai. Šiuo metu apibrėžia S (reikšmingas arba potencialiai reikšmingas atsitiktinis radinys). |
| [LungRecommendation](CodeSystem-lung-recommendation.html) | Tolesnių veiksmų rekomendacijų kodai, susieti su LUNG-RADS kategorijomis (pakartoti po 36 mėnesių, stebėti po 12 / 6 / 3 mėnesių, specialisto konsultacija). |
| [PulmonaryNoduleTypeLocal](CodeSystem-pulmonary-nodule-type-local.html) | Vietinis kodas plaučių mazgelių tipams, kurių neapima SNOMED CT (iš dalies kietas). |
| [PulmonaryNoduleComponentCode](CodeSystem-pulmonary-nodule-component-code.html) | Komponentų kodai plaučių mazgelio stebėjimui (KT pjūvio numeris, sąsaja su pleura). |
| [LungQuestionnaireOptions](CodeSystem-lung-questionnaire-options.html) | Atsakymų variantų kodai ESPBI anketų formoms, naudojamoms Lietuvos plaučių vėžio prevencijos programoje. |

#### Verčių rinkiniai (ValueSet)

| Verčių rinkinys | Aprašymas |
|---|---|
| [LungRadsCategoryVS](ValueSet-lung-rads-category.html) | LUNG-RADS vertinimo kategorijos. |
| [LungRadsModifierVS](ValueSet-lung-rads-modifier.html) | LUNG-RADS modifikatorių kodai. |
| [LungRecommendationVS](ValueSet-lung-recommendation.html) | Tolesnių veiksmų rekomendacijų variantai. |
| [PulmonaryNoduleTypeVS](ValueSet-pulmonary-nodule-type.html) | Plaučių mazgelių tipai (kietas, iš dalies kietas, matinio stiklo, kalcifikuotas, kaverninis). |
| [LungLobeVS](ValueSet-lung-lobe.html) | Plaučių skiltys anatominei lokalizacijai (5 SNOMED CT kūno struktūros kodai). |
| [PulmonaryNoduleMorphologyVS](ValueSet-pulmonary-nodule-morphology.html) | Mazgelio morfologinės savybės (spikuliuoti kraštai, mikrolobuliuoti kraštai). |
| [IncidentalFindingVS](ValueSet-incidental-finding.html) | Reikšmingi atsitiktiniai radiniai, kuriuos galima aptikti LDCT metu (plaučiuose ir už jų ribų), paremti SNOMED CT. |
