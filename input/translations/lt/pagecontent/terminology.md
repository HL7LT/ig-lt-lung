### Terminologija

Šiame puslapyje aprašomos Lietuvos plaučių vėžio diegimo vadove apibrėžtos CodeSystem ir ValueSet kolekcijos.

#### Kodų sistemos (CodeSystem)

| Kodų sistema | Aprašymas |
|---|---|
| [LungRadsCategoryLtLung](CodeSystem-lung-rads-category-lt-lung.html) | LUNG-RADS vertinimo kategorijos (0, 1, 2, 3, 4A, 4B, 4X), paremtos ACR LUNG-RADS v2022. |
| [LungRadsModifierLtLung](CodeSystem-lung-rads-modifier-lt-lung.html) | LUNG-RADS modifikatorių kodai. Šiuo metu apibrėžia S (reikšmingas arba potencialiai reikšmingas atsitiktinis radinys). |
| [LungRecommendationLtLung](CodeSystem-lung-recommendation-lt-lung.html) | Tolesnių veiksmų rekomendacijų kodai, susieti su LUNG-RADS kategorijomis (pakartoti po 36 mėnesių, stebėti po 12 / 6 / 3 mėnesių, specialisto konsultacija). |
| [PulmonaryNoduleTypeLocalLtLung](CodeSystem-pulmonary-nodule-type-local-lt-lung.html) | Vietinis kodas plaučių mazgelių tipams, kurių neapima SNOMED CT (iš dalies kietas). |
| [PulmonaryNoduleComponentCodeLtLung](CodeSystem-pulmonary-nodule-component-code-lt-lung.html) | Komponentų kodai plaučių mazgelio stebėjimui (KT pjūvio numeris, sąsaja su pleura). |
| [LungQuestionnaireOptions](CodeSystem-lung-questionnaire-options.html) | Atsakymų variantų kodai ESPBI anketų formoms, naudojamoms Lietuvos plaučių vėžio prevencijos programoje. |

#### Verčių rinkiniai (ValueSet)

| Verčių rinkinys | Aprašymas |
|---|---|
| [LungRadsCategoryVSLtLung](ValueSet-lung-rads-category-vs-lt-lung.html) | LUNG-RADS vertinimo kategorijos. |
| [LungRadsModifierVSLtLung](ValueSet-lung-rads-modifier-vs-lt-lung.html) | LUNG-RADS modifikatorių kodai. |
| [LungRecommendationVSLtLung](ValueSet-lung-recommendation-vs-lt-lung.html) | Tolesnių veiksmų rekomendacijų variantai. |
| [PulmonaryNoduleTypeVSLtLung](ValueSet-pulmonary-nodule-type-vs-lt-lung.html) | Plaučių mazgelių tipai (kietas, iš dalies kietas, matinio stiklo, kalcifikuotas, kaverninis). |
| [LungLobeVSLtLung](ValueSet-lung-lobe-vs-lt-lung.html) | Plaučių skiltys anatominei lokalizacijai (5 SNOMED CT kūno struktūros kodai). |
| [PulmonaryNoduleMorphologyVSLtLung](ValueSet-pulmonary-nodule-morphology-vs-lt-lung.html) | Mazgelio morfologinės savybės (spikuliuoti kraštai, mikrolobuliuoti kraštai). |
| [IncidentalFindingVS](ValueSet-incidental-finding.html) | Reikšmingi atsitiktiniai radiniai, kuriuos galima aptikti LDCT metu (plaučiuose ir už jų ribų), paremti SNOMED CT. |
