### Terminology

This page describes the CodeSystems and ValueSets defined in the Lithuanian Lung Cancer Implementation Guide.

#### CodeSystems

| CodeSystem | Description |
|---|---|
| [LungRadsCategoryLtLung](CodeSystem-lung-rads-category-lt-lung.html) | LUNG-RADS assessment categories (0, 1, 2, 3, 4A, 4B, 4X) based on ACR LUNG-RADS v2022. |
| [LungRadsModifierLtLung](CodeSystem-lung-rads-modifier-lt-lung.html) | LUNG-RADS modifier codes. Currently defines S (significant or potentially significant incidental finding). |
| [LungRecommendationLtLung](CodeSystem-lung-recommendation-lt-lung.html) | Follow-up recommendation codes mapped to LUNG-RADS categories (repeat at 36 months, follow-up at 12/6/3 months, specialist consultation). |
| [PulmonaryNoduleTypeLocalLtLung](CodeSystem-pulmonary-nodule-type-local-lt-lung.html) | Local code for pulmonary nodule types not covered by SNOMED CT (part-solid). |
| [PulmonaryNoduleComponentCodeLtLung](CodeSystem-pulmonary-nodule-component-code-lt-lung.html) | Component codes for pulmonary nodule observation (CT slice number, pleural association). |
| [LungQuestionnaireOptions](CodeSystem-lung-questionnaire-options.html) | Answer option codes for ESPBI questionnaire forms used in the Lithuanian lung cancer prevention programme. |

#### ValueSets

| ValueSet | Description |
|---|---|
| [LungRadsCategoryVSLtLung](ValueSet-lung-rads-category-vs-lt-lung.html) | LUNG-RADS assessment categories. |
| [LungRadsModifierVSLtLung](ValueSet-lung-rads-modifier-vs-lt-lung.html) | LUNG-RADS modifier codes. |
| [LungRecommendationVSLtLung](ValueSet-lung-recommendation-vs-lt-lung.html) | Follow-up recommendation options. |
| [PulmonaryNoduleTypeVSLtLung](ValueSet-pulmonary-nodule-type-vs-lt-lung.html) | Pulmonary nodule types (solid, part-solid, ground-glass, calcified, cavitary). |
| [LungLobeVSLtLung](ValueSet-lung-lobe-vs-lt-lung.html) | Lung lobes for anatomic localization (5 SNOMED CT body structure codes). |
| [PulmonaryNoduleMorphologyVSLtLung](ValueSet-pulmonary-nodule-morphology-vs-lt-lung.html) | Nodule morphology features (spiculated margins, microlobulated margins). |
| [IncidentalFindingVS](ValueSet-incidental-finding.html) | Significant incidental findings detectable during LDCT (pulmonary and extra-pulmonary), based on SNOMED CT. |
