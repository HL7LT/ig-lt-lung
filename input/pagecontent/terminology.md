### Terminology

This page describes the CodeSystems and ValueSets defined in the Lithuanian Lung Cancer Implementation Guide.

#### CodeSystems

| CodeSystem | Description |
|---|---|
| [LungRadsCategory](CodeSystem-lung-rads-category.html) | LUNG-RADS assessment categories (0, 1, 2, 3, 4A, 4B, 4X) based on ACR LUNG-RADS v2022. |
| [LungRadsModifier](CodeSystem-lung-rads-modifier.html) | LUNG-RADS modifier codes. Currently defines S (significant or potentially significant incidental finding). |
| [LungRecommendation](CodeSystem-lung-recommendation.html) | Follow-up recommendation codes mapped to LUNG-RADS categories (repeat at 36 months, follow-up at 12/6/3 months, specialist consultation). |
| [PulmonaryNoduleTypeLocal](CodeSystem-pulmonary-nodule-type-local.html) | Local code for pulmonary nodule types not covered by SNOMED CT (part-solid). |
| [PulmonaryNoduleComponentCode](CodeSystem-pulmonary-nodule-component-code.html) | Component codes for pulmonary nodule observation (CT slice number, pleural association). |
| [LungQuestionnaireOptions](CodeSystem-lung-questionnaire-options.html) | Answer option codes for ESPBI questionnaire forms used in the Lithuanian lung cancer prevention programme. |

#### ValueSets

| ValueSet | Description |
|---|---|
| [LungRadsCategoryVS](ValueSet-lung-rads-category.html) | LUNG-RADS assessment categories. |
| [LungRadsModifierVS](ValueSet-lung-rads-modifier.html) | LUNG-RADS modifier codes. |
| [LungRecommendationVS](ValueSet-lung-recommendation.html) | Follow-up recommendation options. |
| [PulmonaryNoduleTypeVS](ValueSet-pulmonary-nodule-type.html) | Pulmonary nodule types (solid, part-solid, ground-glass, calcified, cavitary). |
| [LungLobeVS](ValueSet-lung-lobe.html) | Lung lobes for anatomic localization (5 SNOMED CT body structure codes). |
| [PulmonaryNoduleMorphologyVS](ValueSet-pulmonary-nodule-morphology.html) | Nodule morphology features (spiculated margins, microlobulated margins). |
| [IncidentalFindingVS](ValueSet-incidental-finding.html) | Significant incidental findings detectable during LDCT (pulmonary and extra-pulmonary), based on SNOMED CT. |
